# 독일어 학습 완전 가이드
> 목적: 독일 취업 비자 요건(A2) + 현지 취업 경쟁력(B1) 확보
> 비용: 무료~12만원 (공인 시험)
> 기간: A2까지 6개월, B1까지 12개월 (하루 30분~1시간 기준)

---

## 1. 왜 독일어가 필요한가

| 목적 | 필요 수준 | 비고 |
|------|----------|------|
| Anerkennungspartnerschaft 비자 | **A2 필수** | 없으면 비자 신청 불가 |
| Job Seeker Visa | A1 | A2 준비하면 자동 충족 |
| 현지 취업 경쟁력 | B1 권장 | 회의, 이메일, 동료 소통 |
| 자동차 기술 문서 독해 | B2 이상 | 장기 목표 |

> 영어만으로도 지원 가능한 포지션이 있지만,
> 독일어 A2라도 있으면 서류 통과율이 크게 높아집니다.

---

## 2. 독일어 레벨 이해 (CEFR 기준)

```
A1 (입문)   → 기초 인사, 숫자, 날짜
A2 (초급)   → 일상 대화, 간단한 업무 소통  ← 비자 최소 요건
B1 (중급)   → 업무 회의, 이메일 작성       ← 취업 권장
B2 (중상급) → 기술 문서 독해, 발표         ← 장기 목표
C1 (고급)   → 원어민 수준 업무
```

## 3. 무료 학습 커리큘럼 — A1에서 A2까지 (6개월)

### 핵심 무료 플랫폼 3개

**1. Deutsche Welle (DW) Learn German — 메인 교재**
- URL: dw.com/en/learn-german (영어 기반)
- 구성: Nicos Weg (드라마 형식), Deutsch Warum Nicht?, 발음 교정
- Nicos Weg A1 (90개 에피소드) → Nicos Weg A2 (90개 에피소드)
- 완전 무료, 앱도 있음 (DW Learn German 앱)
- **추천 순서**: Nicos Weg A1 → A2 순서대로 진행

**2. Duolingo — 보조 어휘 유지**
- URL: duolingo.com / 앱 설치
- 메인 학습보다 복습 및 유지용
- 매일 10분 → 어휘 유지

**3. Anki — 어휘 암기**
- URL: apps.ankiweb.net (무료)
- 독일어 단어장 덱 다운로드: ankiweb.net/shared/decks → "German" 검색
- 추천 덱: "German A1/A2 Vocabulary" (무료)
- 매일 20단어 새로 학습 + 복습

### 6개월 월별 학습 계획 (하루 45분)

#### Month 1: A1 기초 (DW Nicos Weg A1 시작)

**학습 목표:**
- 인사말: Hallo, Guten Morgen, Wie geht es Ihnen?
- 숫자 1~100
- 요일, 월, 시간 표현
- 기본 동사: sein(이다), haben(가지다), machen(하다)
- 명사 + 관사: der/die/das 개념 이해

**매일 루틴 (45분):**
```
15분 — DW Nicos Weg 에피소드 1개 (약 3~5분 영상 + 연습문제)
15분 — Anki 어휘 (새 단어 15개 + 복습)
15분 — Duolingo 1세션
```

**Month 1 완료 기준:** Nicos Weg A1 에피소드 30개 완료

---

#### Month 2: A1 심화

**학습 목표:**
- 동사 변화: 규칙 동사 + 불규칙 동사 (gehen, fahren, kommen)
- 격 변화: Nominativ(주격), Akkusativ(목적격) 이해
- 가족, 직업, 나라 어휘
- 간단한 문장 만들기: "Ich arbeite als Ingenieur."

**매일 루틴 (45분):**
```
20분 — DW Nicos Weg 에피소드 2개
15분 — Anki 어휘
10분 — 영작 연습: 자기 소개 문장 5개 독어로 쓰기
```

**Month 2 완료 기준:** Nicos Weg A1 에피소드 60개 완료

---

#### Month 3: A1 마무리 + A2 진입

**학습 목표:**
- A1 전체 복습
- 과거형(Perfekt) 시작: "Ich habe gearbeitet."
- 전치사: in, auf, mit, von
- 숫자를 이용한 시간, 날짜 표현 완성

**매일 루틴 (45분):**
```
20분 — DW Nicos Weg A1 마무리 + A2 시작
15분 — Anki 어휘 (A2 덱 추가)
10분 — 쓰기 연습: 짧은 이메일 형식 작성
```

**Month 3 완료 기준:** Nicos Weg A1 전체 완료, A2 시작

---

#### Month 4: A2 본격 학습

**학습 목표:**
- 복합 문장: weil(왜냐하면), dass(~라는 것), wenn(~할 때)
- 미래형: werden + Infinitiv
- 직장/업무 관련 어휘 집중
  - Arbeit(일), Kollege(동료), Besprechung(회의), Bericht(보고서)
  - Prüfung(시험), Qualität(품질), Software(소프트웨어)

**업무 독일어 핵심 표현:**

| 독일어 | 한국어 |
|--------|--------|
| Ich möchte mich vorstellen. | 자기소개하고 싶습니다. |
| Ich habe X Jahre Erfahrung in... | 저는 X년 경험이 있습니다... |
| Könnten Sie das bitte wiederholen? | 다시 말씀해 주시겠어요? |
| Ich verstehe das nicht ganz. | 잘 이해하지 못했습니다. |
| Das Treffen findet um X Uhr statt. | 회의는 X시에 있습니다. |
| Ich habe eine Frage. | 질문이 있습니다. |

**매일 루틴 (1시간):**
```
25분 — DW Nicos Weg A2
20분 — Anki (A2 어휘 집중)
15분 — 업무 독일어 표현 암기
```

---

#### Month 5: A2 심화

**학습 목표:**
- Dativ(여격) 완성: dem/der/dem
- 재귀동사: sich vorstellen, sich bewerben(지원하다)
- 구직 관련 어휘:
  - Lebenslauf(이력서), Bewerbung(지원서), Vorstellungsgespräch(면접)
  - Stelle(포지션), Gehalt(급여), Arbeitsvertrag(고용계약서)
- 전화/화상 독일어 기초

**Month 5 핵심 문장 외우기:**
```
Guten Tag, mein Name ist Suhwan Jeon.
Ich bewerbe mich für die Stelle als Diagnostic Engineer.
Ich habe 5 Jahre Erfahrung in der Fahrzeugdiagnose.
Ich kenne CANoe und UDS sehr gut.
Ich bin an einer Stelle in Deutschland sehr interessiert.
```

**매일 루틴 (1시간):**
```
25분 — DW Nicos Weg A2
20분 — Anki + 구직 어휘
15분 — 위 문장 소리 내어 말하기 연습
```

---

#### Month 6: A2 마무리 + 시험 준비

**학습 목표:**
- A2 전체 복습
- 시험 유형 파악 (듣기/읽기/쓰기/말하기)
- 모의시험 풀기

**모의시험 자료:**
- DW 공식 A2 모의시험: dw.com/en/learn-german → "Tests"
- 괴테 인스티투트 공식 샘플: goethe.de → "Examinations" → A2 샘플
- telc 샘플 문제: telc.net → "Sample Papers"

**매일 루틴 (1시간):**
```
30분 — 모의시험 섹션별 연습
20분 — 취약 부분 복습
10분 — 말하기 연습 (혼자 독일어로 자기소개)
```

## 4. 공인 시험 — A2 취득

### 옵션 1: Goethe-Zertifikat A2 (추천)

| 항목 | 내용 |
|------|------|
| 주관 | 괴테 인스티투트 서울 |
| 비용 | 약 90,000~120,000원 |
| 시험 구성 | 듣기(30분) + 읽기(30분) + 쓰기(30분) + 말하기(15분) |
| 합격 기준 | 각 파트 60% 이상 |
| 독일 인정 | 비자 신청 공식 인정 |
| 예약 | goethe.de/seoul → "Prüfungen" → A2 일정 |
| 시험 빈도 | 연 4~6회 |

**등록 절차:**
1. goethe.de → 서울 인스티투트 접속
2. 회원가입
3. 시험 일정 확인 (보통 2~3개월 전 접수 시작)
4. 온라인 결제
5. 시험 당일: 신분증 지참

### 옵션 2: telc Deutsch A2

| 항목 | 내용 |
|------|------|
| 주관 | telc 공인 파트너 기관 (한국 내 여러 곳) |
| 비용 | 약 80,000~100,000원 |
| 특징 | 괴테와 동등하게 독일 이민청 인정 |

## 6. 자동차 기술 독일어 핵심 어휘

독일 자동차 회사 JD와 기술 문서에 자주 나오는 용어:

| 독일어 | 영어 | 한국어 |
|--------|------|--------|
| Fahrzeugdiagnose | Vehicle Diagnostics | 차량 진단 |
| Steuergerät (ECU) | Control Unit | 전자 제어 유닛 |
| Diagnoseprotokoll | Diagnostic Protocol | 진단 프로토콜 |
| Softwareentwicklung | Software Development | 소프트웨어 개발 |
| Qualitätssicherung | Quality Assurance | 품질 보증 |
| Testautomatisierung | Test Automation | 테스트 자동화 |
| Fehlerbehebung | Debugging / Troubleshooting | 오류 수정 |
| Anforderungen | Requirements | 요구사항 |
| Prüfbericht | Test Report | 테스트 보고서 |
| Inbetriebnahme | Commissioning | 시운전 |
| Fahrerassistenzsystem | ADAS | 운전자 보조 시스템 |
| Bussystem | Bus System | 버스 시스템 (CAN 등) |
| Ethernet-Diagnose | Ethernet Diagnostics | 이더넷 진단 (DoIP) |
