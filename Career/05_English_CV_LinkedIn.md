# 영문 CV + LinkedIn 완전 가이드
> 목적: 해외 채용 담당자와 ATS(자동 스크리닝 시스템)를 모두 통과하는 서류 준비
> 참고: 한국식 이력서와 완전히 다른 접근법 필요

---

## 1. 영문 CV vs 한국 이력서 핵심 차이

| 항목 | 한국 이력서 | 영문 CV |
|------|-----------|---------|
| 사진 | 필수 | **절대 넣지 않음** |
| 나이/성별 | 기재 | **기재하지 않음** |
| 주민번호 | 기재 | **없음** |
| 분량 | 1장 | **1~2장** (경력 10년 이상은 2장까지 허용) |
| 내용 방식 | 업무 나열 | **결과/성과 중심** |
| 자기소개서 | 별도 | Cover Letter (선택, 회사마다 다름) |
| 목적 | 사람이 읽음 | **ATS가 먼저 읽고, 사람이 나중에 읽음** |

---

## 2. ATS(Applicant Tracking System)란?

대부분의 글로벌 기업은 이력서를 사람이 먼저 읽지 않습니다.  
ATS 소프트웨어가 먼저 키워드를 스캔하고 점수를 매깁니다.

**ATS를 통과하는 조건:**
- JD(직무 설명)에 있는 키워드가 CV에 포함될 것
- 특수 문자, 표, 이미지 사용 최소화
- 표준 섹션 이름 사용 (Experience, Education, Skills 등)
- PDF 또는 DOCX 포맷 (PDF 권장)

**ATS에서 실패하는 이유:**
- 화려한 디자인/그래픽
- 표 안에 텍스트 넣기
- 헤더/푸터에 중요 정보 넣기
- JD 키워드 미포함

## 3. CV 구조 (섹션별 작성법)

### 기본 템플릿 구조

```
[이름]
[이메일] | [전화번호] | [LinkedIn URL] | [위치: Seoul, Korea]

PROFESSIONAL SUMMARY
(3~4줄)

EXPERIENCE
(역순으로 — 최신 직장 먼저)

CERTIFICATIONS
(취득한 자격증)

SKILLS
(기술 키워드)

EDUCATION
(학력)
```

---

### Section 1: Header (헤더)

```
Gildong Hong
g.hong@email.com | +82-10-XXXX-XXXX | linkedin.com/in/gildong-hong | Seoul, South Korea
```

- 주소는 도시 + 국가만 (상세 주소 불필요)
- GitHub 링크가 있으면 추가

---

### Section 2: Professional Summary (핵심 요약)

3~4문장. 본인이 누구인지, 핵심 경험, 목표를 간결하게.

**나쁜 예:**
> "I am a hardworking and motivated engineer with passion for automotive industry looking for new opportunities."

→ 아무 정보가 없음. 모든 사람이 이렇게 씀.

**좋은 예:**
> "IVI Test Engineer with 6+ years of experience in automotive diagnostic communication and software validation, specializing in UDS (ISO 14229), DoIP (ISO 13400), and pre-production vehicle testing. Proven track record of validating complex IVI systems for Hyundai global markets and conducting DoIP-based diagnostics for Jaguar Land Rover vehicles. Seeking to leverage automotive SPICE and ISO 26262 expertise in an overseas validation or assessment role."

→ 숫자, 기술명, 브랜드, 목표가 모두 포함됨.

---

### Section 3: Experience (경력) — 가장 중요

**형식:**

```
Job Title | Company Name | Location | Start Date – End Date

• [동사] [무엇을] [결과/규모]
• [동사] [무엇을] [결과/규모]
• [동사] [무엇을] [결과/규모]
```

**규칙:**
- 동사는 항상 과거형 (현재 직장은 현재형)
- 수치 포함 필수 (몇 개 차량, 몇 개 테스트 케이스, 몇 % 개선)
- 한 회사당 bullet point 3~6개

**동사 예시 (직무별):**

| 유형 | 동사 |
|------|------|
| 분석 | Analyzed, Investigated, Diagnosed, Evaluated |
| 개발 | Developed, Created, Built, Implemented |
| 수행 | Executed, Conducted, Performed, Ran |
| 관리 | Managed, Coordinated, Led, Oversaw |
| 개선 | Improved, Optimized, Reduced, Enhanced |
| 협업 | Collaborated, Coordinated, Communicated |

## 4. CV 검토 체크리스트

작성 완료 후 스스로 확인:

```
[ ] 사진, 나이, 성별 없는지 확인
[ ] 2페이지 초과하지 않는지 확인
[ ] 각 경력 bullet point가 동사로 시작하는지 확인
[ ] 수치(숫자)가 최소 1개 이상 포함되어 있는지 확인
[ ] 지원하는 JD의 키워드가 CV에 포함되어 있는지 확인
[ ] 표나 이미지를 사용하지 않았는지 확인
[ ] PDF 저장 후 ATS 시뮬레이터로 테스트
[ ] 오탈자 없는지 확인 (Grammarly 사용 권장)
```

### ATS 무료 테스트 도구

- **Jobscan** (jobscan.co): CV와 JD를 넣으면 키워드 매칭률 점수 제공
- **Resume Worded** (resumeworded.com): CV 품질 자동 피드백

## 5. LinkedIn 프로필 완전 최적화

### LinkedIn이 중요한 이유

독일/영국/싱가포르 리크루터의 80% 이상이 LinkedIn에서 후보자를 먼저 검색합니다.  
이력서를 보내기 전에 LinkedIn이 먼저 발견되는 경우가 더 많습니다.

---

### 프로필 각 섹션 작성법

**Profile Photo (프로필 사진)**
- 단색 배경, 얼굴 정면, 비즈니스 캐주얼
- 스마트폰으로도 충분 (조명만 좋으면 됨)
- 사진 있는 프로필이 없는 것보다 조회수 14배 높음

**Headline (헤드라인)**
- 기본값은 직함 + 회사명 → 이보다 더 정보를 담아야 함

나쁜 예:
> `IVI Test Engineer at FPT Korea`

좋은 예:
> `IVI Test Engineer | UDS/DoIP Automotive Diagnostics | Automotive SPICE | Open to Global Opportunities`

**About (소개)**
3~5문단, 300~400단어. 당신의 스토리.

구조:
1. 현재 무엇을 하는지 (1문단)
2. 핵심 전문성 (1~2문단)
3. 차별점 (1문단)
4. 목표/찾고 있는 것 (1문단)

예시:
> I am an IVI Test Engineer currently working at Hyundai Motor R&D Center, where I validate pre-production vehicles for global markets. With over 6 years in automotive software validation and diagnostic communication, I specialize in UDS (ISO 14229), DoIP (ISO 13400), and systems-level testing of infotainment and connected vehicle platforms.
>
> My background began at EasyDES, where I joined a small, specialized team to analyze OEM diagnostic protocols for international vehicle brands. Rather than learning UDS from a textbook, I built my understanding by directly working with real vehicles — capturing communication logs, building diagnostic simulators, and supporting global dealers in English. This hands-on foundation gave me a deep understanding of how automotive ECUs actually communicate, beyond what the standard specifies.
>
> One of my most distinctive experiences was leading a DoIP analysis project for Jaguar Land Rover vehicles, where I built Ethernet diagnostic environments from scratch and extended DoIP-connected vehicles to support UDS-based diagnostic functions — an area where very few engineers have real vehicle experience.
>
> I am currently preparing for international opportunities in automotive software validation, A-SPICE assessment, and functional safety engineering. I am targeting roles in Germany, the UK, and Singapore where I can combine my technical depth with globally recognized certifications.

**Experience (경력)**
- CV와 동일하게 작성
- LinkedIn은 길게 써도 됨 (PDF CV보다 여유 있게)
- 각 역할에 핵심 성과 3~5개

**Skills (스킬)**
- 최대 50개까지 추가 가능
- 추가 필수 키워드: `Automotive SPICE`, `UDS`, `DoIP`, `CANoe`, `ISO 26262`, `Regression Testing`, `IVI Systems`, `CAN Bus`, `Functional Safety`, `Vehicle Diagnostics`
- 동료에게 Endorsement 요청

**Certifications**
- 취득할 때마다 즉시 추가

**Open to Work 설정**
- "Open to Work" 배너 → 리크루터에게만 보이는 옵션 선택 (회사 동료에게 숨김)
- 타겟 직종, 타겟 국가, 취업 유형 설정

---

### LinkedIn 활동 전략

**주 1~2회:**
- 자동차 기술 관련 게시물에 댓글 달기 (A-SPICE, ISO 26262, automotive testing 관련)
- 관심 회사(ETAS, Bosch, Continental)의 게시물 팔로우 + 좋아요

**월 1회:**
- 본인의 경험이나 학습 내용을 짧은 글로 작성
- 예: "JLR DoIP 분석 중 발견한 것" → 영어로 300단어 게시물

**연결 500명 목표:**
- LinkedIn 검색: "Automotive SPICE", "ISO 26262", "IVI engineer" → 관련자들에게 연결 요청
- 연결 요청 메시지 예시:
> "Hi [Name], I came across your profile and noticed your experience in A-SPICE assessment. I'm currently preparing for the Intacs CPA certification and would love to connect with professionals in this field. I hope we can learn from each other."

## 6. 커버 레터 (Cover Letter)

모든 회사가 요구하지는 않지만, 요구할 경우 아래 구조로 작성:

```
[날짜]

[채용 담당자 이름, 없으면 "Hiring Manager"]
[회사명]

Dear [이름] / Dear Hiring Manager,

[1문단] 지원 동기 — 이 회사, 이 포지션에 왜 관심을 가졌는지
[2문단] 핵심 경험 — JD와 직접 연결되는 경험 2~3가지
[3문단] 왜 이 회사인지 — 회사 특성/프로젝트에 대한 구체적 언급
[4문단] 마무리 — 인터뷰 기회 요청

Sincerely,
[이름]
```

→ 1페이지 이내, 500단어 이하

## 7. 포트폴리오 문서 작성 방법

### 무엇을 만들어야 하는가

채용 담당자가 "이 사람 진짜 뭘 할 줄 아는지"를 볼 수 있는 문서.

**당신이 만들어야 할 문서 3개:**

**문서 1: JLR DoIP Analysis Case Study**
```
제목: Ethernet-Based DoIP Diagnostic Implementation for JLR Vehicles
내용:
- 배경: 왜 이 프로젝트가 필요했는가
- 환경 구축: 케이블, Ethernet 설정, DoIP 스택 구성
- 분석 방법: 어떤 도구로, 어떻게 분석했는가
- 결과: UDS-over-DoIP 기능 구현, 발견된 주요 사항
- 학습: 이 경험에서 얻은 기술적 인사이트
분량: 1~2페이지
```

**문서 2: UDS Diagnostic Simulator Development**
```
제목: OEM Diagnostic Simulator Design for UDS Protocol Testing
내용:
- 문제: OEM 진단기 없이 테스트하는 방법이 필요했음
- 접근법: 시뮬레이터 설계 방법
- 구현: 어떤 도구/방법으로 만들었는가
- 활용: 어떤 테스트/검증에 사용되었는가
분량: 1~2페이지
```

**문서 3: IVI Validation Process Overview**
```
제목: Pre-production IVI System Validation at Hyundai R&D
내용:
- 역할과 책임
- 테스트 범위 및 방법
- 사용 도구 (CANoe, PCAN 등)
- 협업 구조 (베트남 팀, 현대 연구원)
- 이슈 발견 및 관리 프로세스
분량: 1페이지
```

### 포트폴리오 형식

- **Notion 페이지** (링크 공유 — 가장 편리)
- **Google Docs** (링크 공유)
- **GitHub README** (기술적 신뢰도 높음)
- **PDF** (이메일 첨부)

→ LinkedIn 프로필의 Featured 섹션에 링크 추가.

## 8. 국가별 CV 차이점

| 국가 | 차이점 |
|------|--------|
| **독일** | Lebenslauf (이력서) 형식, 사진 넣는 경우 있음 → 영어 JD라면 국제 형식 OK |
| **영국** | 미국식과 거의 동일, CV라는 단어 선호 |
| **싱가포르** | 미국식 Resume 형식, 1~2페이지 |
| **캐나다/호주** | Resume 형식, 1~2페이지 |

→ 독일 현지 회사에 독일어 JD로 지원 시에는 독일식 형식 고려 필요.  
영어 JD로 지원 시에는 국제 표준 형식으로 통일 가능.
