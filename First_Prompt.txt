There are various files and folders inside the Data folder.

First, read the RULE.md file and follow the rules.

Then, understand the structure of the HiSponsor_Ver1, HiSponsor_Ver2, and HiSponsor_Ver3 folders ("Absolutely no modification, addition, or removal").

After that, read the prompts in the Prompts folder sequentially.

When reading a prompt and performing a task,

create a folder named after the prompt (e.g., Claude_1_Prompt) in the output folder, and generate the work for the read prompt inside that folder.

For example,

When reading Claude_1_Prompt and creating a file, work in the \Data\output\Claude_1_Prompt folder.

When reading Gemini_2_Prompt and creating a file, work in the \Data\output\Gemini_2_Prompt folder.

Please manage files and folders so that they do not overlap
