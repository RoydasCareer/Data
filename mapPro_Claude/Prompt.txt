# 🌍 GlobeTravel Log — 지구본 여행 기록 웹 서비스 구현 지시서

## [역할 정의]
너는 풀스택 웹 개발 전문가다.
아래 명세를 읽고 로컬에서 완전히 동작하는 단일 HTML 파일(또는 최소한의 파일 구조)로
여행 기록 서비스를 구현하라.
외부 프레임워크는 CDN으로 불러오고, 백엔드 없이 브라우저 localStorage만으로 데이터를 저장한다.
네이버/티스토리/깃허브 블로그에 <iframe>으로 임베딩 가능한 구조로 만들어야 한다.

---

## [서비스 개요]
- 서비스명: GlobeTravel Log (임시, 변경 가능)
- 핵심 컨셉: 구글 어스처럼 위성에서 내려다보는 시점의 지구본 위에
  사용자의 여행 기록(방문 지역, 사진, 이동 경로)을 시각화하는 웹 서비스
- 지구본 스타일: 실사 위성 이미지가 아닌, 구글맵/네이버맵/카카오맵과 같은
  2D 벡터 스타일의 타일 맵을 구형(Globe)으로 렌더링
  → Three.js + OpenLayers 또는 Three.js + Leaflet 조합을 사용하되,
  가장 자연스럽게 구현 가능한 방법을 선택할 것
  → 대안: Mapbox GL JS의 Globe Projection 사용 (무료 Public Token 사용)
  → 또 다른 대안: CesiumJS + OpenStreetMap 타일 (무료)
  → 최종 권장: CesiumJS(무료) + OSM 타일 or Mapbox Globe Projection
- 로컬 완전 동작: 인터넷 연결 시 타일 맵 표시, localStorage 기반 데이터 저장
- 블로그 임베딩: 완성 후 <iframe src="..." width="100%" height="600px"> 형태로 삽입 가능

---

## [기술 스택 선택 기준]
아래 우선순위로 기술을 선택하라:
1순위: Mapbox GL JS (Globe Projection) - API Key 필요하지만 무료 티어 충분
2순위: CesiumJS + OpenStreetMap - 완전 무료, 오픈소스
3순위: Three.js + Leaflet 커스텀 구현

→ 네가 판단하기에 가장 안정적이고 기능 구현이 용이한 스택을 선택하고,
  선택 이유를 코드 상단 주석에 명시하라.

## [구현 기능 명세]

### ■ 기본 UI 레이아웃
- 전체 화면을 지구본이 차지 (배경: 우주 느낌의 어두운 색상 #0a0a1a 또는 별 배경)
- 우측 또는 하단에 기능 패널(사이드바) 배치
- 반응형 디자인 (모바일/태블릿/PC 모두 대응)
- 전체적인 UI 테마: 다크 모드, 미니멀, 여행 느낌 (폰트: Google Fonts Noto Sans KR)

---

### ■ 기능 1: 지역 표시 (Location Marker)

#### 1-1. 수동 입력
- 사이드바에 "지역 추가" 버튼
- 클릭 시 모달 팝업:
  - 지역명 입력 (텍스트, 예: "태국 방콕")
  - 위도/경도 직접 입력 OR 지도 클릭으로 좌표 선택
  - 방문일자 선택 (date picker)
  - 메모 입력 (textarea)
  - 저장 버튼
- 저장된 지역은 지구본 위에 마커(핀)로 표시
  - 마커 스타일: 원형 글로우 이펙트, 방문 횟수에 따라 크기 차등
  - 마커 hover 시 지역명 툴팁 표시
  - 마커 클릭 시 기능 2(사진 라이브러리) 패널 오픈

#### 1-2. 사진 위치 정보 기반 자동 입력
- "사진으로 위치 추가" 버튼
- 사용자가 이미지 파일을 선택하면 EXIF 데이터에서 GPS 좌표 추출
  → exifr.js 라이브러리 사용 (CDN)
- GPS 정보가 있으면 자동으로 위도/경도 추출 후 지역명 입력 모달 표시
  (역지오코딩: Nominatim API 무료 사용하여 좌표 → 지역명 자동 입력)
- GPS 정보가 없는 사진은 "위치 정보 없음" 안내 후 수동 입력 유도
- 데이터 저장: localStorage에 JSON 구조로 저장

#### 1-3. 마커 관리
- 마커 우클릭 시 컨텍스트 메뉴: [편집] [삭제]
- 전체 마커 목록을 사이드바에 리스트로 표시
- 리스트 항목 클릭 시 해당 위치로 지구본 회전 + 줌

---

### ■ 기능 2: 사진 라이브러리

#### 2-1. 사진 업로드
- 지역 마커 클릭 → 해당 지역의 사진 라이브러리 패널 슬라이드 인
- 패널 내 "사진 추가" 버튼 → 파일 선택 다이얼로그 (multiple 허용)
- 선택된 사진들은 해당 지역 ID에 매핑되어 저장
  - 사진 원본은 Base64로 인코딩하여 localStorage에 저장
    (용량 제한 안내: localStorage 5MB 제한, 초과 시 경고 메시지)
  - 향후 IndexedDB 마이그레이션 가능하도록 데이터 구조 설계

#### 2-2. 다중 사진 + 자동 지역 분류
- "사진 일괄 업로드" 기능:
  - 여러 장의 사진을 한 번에 선택
  - 각 사진의 EXIF GPS 데이터 추출
  - GPS 좌표가 있는 사진 → 기존 등록 지역 중 반경 50km 이내 지역에 자동 분류
  - GPS 좌표가 없거나 매칭 지역 없음 → "미분류" 보관함에 임시 저장 후 사용자에게 수동 배정 요청
  - 진행 상황 프로그레스 바 표시

#### 2-3. 사진 뷰어
- 갤러리 그리드 레이아웃 (3열 기본)
- 사진 클릭 → 라이트박스 풀스크린 뷰어
  - 좌우 화살표로 이전/다음 탐색
  - 촬영 날짜, 파일명, 메모 표시
  - 삭제 버튼 (확인 다이얼로그 포함)
- 사진 드래그 앤 드롭 업로드 지원

---

### ■ 기능 3: 이동 경로 시각화

#### 3-1. 경로 추가 UI
- 사이드바 "경로 추가" 버튼 → 모달 팝업:
  - 출발지 선택: 텍스트 입력 + 자동완성 (Nominatim API)
  - 도착지 선택: 텍스트 입력 + 자동완성 (Nominatim API)
  - 교통수단 선택 (아이콘 버튼 UI):
    ✈️ 비행기 | 🚗 자동차 | 🚆 기차 | 🚌 버스 | 🚴 자전거 | 🚶 도보 | 🚢 배/크루즈
  - 교통수단별 추가 정보 입력:
    - 비행기: 항공사명, 편명 입력 (예: VietJet, VJ831)
    - 기차: 노선명
    - 기타: 메모
  - 이동 날짜 선택
  - 저장 버튼

#### 3-2. 경로 렌더링
- 경로 유형에 따라 다른 렌더링:

  [비행기]
  - 출발지 → 도착지를 잇는 대원 곡선(Great Circle Arc) 3D 호로 표시
  - 곡선 색상: 하늘색 계열 (#4fc3f7), 반투명 글로우 이펙트
  - 곡선 위에 비행기 아이콘(✈ 또는 SVG 커스텀 아이콘)이 출발지 → 도착지 방향으로
    부드럽게 애니메이션 이동 (30~60초 주기로 반복, 속도는 눈에 거슬리지 않게)
  - 비행기 아이콘은 이동 방향으로 자동 회전

  [자동차/버스/자전거/도보]
  - 직선 또는 곡선 경로 표시
  - 색상: 교통수단별 구분색 (자동차: 주황, 기차: 초록, 버스: 파랑, 자전거: 노랑, 도보: 흰색)
  - 점선 또는 실선 구분

  [기차]
  - 선로 스타일 점선 경로

- 경로 hover 시 툴팁: "출발지 → 도착지 | 교통수단 | 항공사(해당시) | 날짜"
- 경로 클릭 시 상세 정보 사이드 패널

#### 3-3. 경로 관리
- 사이드바에 전체 경로 리스트 표시
- 경로별 표시/숨김 토글
- 경로 삭제 기능

---

### ■ 기능 4: 통계 및 대시보드 (부가 기능)
- 사이드바 하단 또는 별도 탭:
  - 총 방문 국가 수
  - 총 방문 도시 수
  - 총 이동 거리 (km)
  - 사용 교통수단 비율 (텍스트 또는 간단한 숫자 표시)
  - 방문 연도 타임라인

## [외부 라이브러리 (모두 CDN)]
- Mapbox GL JS or CesiumJS: 지구본 렌더링
- exifr.js: 사진 EXIF 데이터 추출
- Nominatim API (OpenStreetMap): 역지오코딩, 장소 자동완성 (무료, 무API키)
- Google Fonts (Noto Sans KR): 한국어 폰트
- Animate.css or 순수 CSS: UI 애니메이션
- uuid.js 또는 crypto.randomUUID(): 고유 ID 생성

---

## [구현 순서 (Autopilot 지시)]
아래 순서대로 단계적으로 구현하고 각 단계 완료 시 알려라:

STEP 1: 기본 HTML 구조 + 지구본 렌더링 (2D 스타일 맵이 구형으로 표시)
STEP 2: 우주 배경 + UI 레이아웃 (사이드바, 다크 테마, 반응형)
STEP 3: 기능 1 구현 - 지역 마커 추가/표시/삭제
STEP 4: 기능 2 구현 - 사진 업로드, EXIF 추출, 갤러리 뷰어
STEP 5: 기능 3 구현 - 경로 추가, 대원 곡선, 비행기 애니메이션
STEP 6: 기능 4 구현 - 통계 대시보드
STEP 7: 전체 통합 테스트 + 반응형 검증 + 블로그 임베딩 가이드 출력

## [품질 기준]
- 모든 기능은 인터넷 연결 상태에서 로컬 브라우저에서 완전히 동작해야 함
- 새로고침 후에도 데이터 유지 (localStorage 영속성)
- 한국어 UI 기본
- 크롬 기준 오류 없음
- 코드 내 한국어 주석 포함
- 모든 파일은 단일 폴더 내에서 동작
- 완성 후 index.html 파일만 열어도 전체 서비스 실행 가능
