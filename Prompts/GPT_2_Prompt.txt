# PROJECT: HiSponsor (AI-powered Global Job Sponsorship Blog Platform)

## 🎯 Goal

Build a fully automated AI-driven blog platform that:

* Collects visa sponsorship job postings globally
* Processes and structures them
* Publishes SEO-optimized blog posts
* Supports Korean and English
* Is maintainable by NON-developers

---

# 🧠 SYSTEM ARCHITECTURE

## Core Stack

* Automation: Make.com
* Database: Google Sheets
* AI Processing:

  * Processing: GPT / Gemini
  * Validation: Claude
  * Search: Perplexity
* Version Control: GitHub
* Hosting: Cloudflare Pages

---

# 🤖 AI AGENT SYSTEM

## 1. PM Agent (Controller)

* Controls workflow
* Requests approval from user
* Handles retry logic
* Sends reports via Telegram

## 2. Monitoring Agents (Multi-source)

* Monitor:

  * RSS feeds
  * Job platforms
  * Visa info sites
* Detect new data
* Send to raw_queue

## 3. Collection Agent

* Fetch HTML
* Extract structured data using AI
* Output JSON

## 4. Processing Agent

* Convert data into blog content
* SEO optimized
* Category-specific formatting

## 5. Translation Agent

* Korean → English
* Natural translation
* Preserve meaning

## 6. Validation Agent (Read-only)

* Grammar check
* Fact check
* Visa law validation
* Structure validation
* Reports issues ONLY

## 7. Publishing Agent

* Convert to Markdown
* Push to GitHub
* Trigger Cloudflare deployment

## 8. Developer AI Agent

* Weekly system analysis
* Suggest improvements
* Detect bottlenecks

# 🗂 DATABASE STRUCTURE (Google Sheets)

## Spreadsheet: HiSponsor_Database

### raw_queue

id | source | url | title | detected_at | data_type | status | error_count

### collected

id | raw_id | data_type | source | company | job_title | location | visa_type | salary | raw_content | collected_at | status

### processed

id | collected_id | category | title_ko | title_en | body_ko | body_en | seo_keywords | quality_score | processed_by | processed_at | status

### translated

id | processed_id | title_ko | title_en | body_ko | body_en | translated_at | status

### validated

id | translated_id | final_score | grammar_ok | fact_ok | law_ok | structure_ok | validated_at | approved | approved_at | slug

### rejected

id | translated_id | fail_reason | rejected_at | retry_count | status

### published

id | validated_id | slug | github_path | published_at | url | category | status
