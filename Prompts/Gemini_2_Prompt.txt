# PROJECT NAME: HiSponsor Ver 4 (Global Visa & Job Platform)

## 1. CORE OBJECTIVE
Build a modular, scalable web platform for visa information, automated job listings, and a resume template marketplace. The system must be designed for a non-programmer to maintain and operate easily.

## 2. STRICT RULES (MANDATORY)
- **Compliance:** You MUST strictly follow the 'RULE.md' file at all times during the development process.
- **Documentation:** Create two separate README files: 'README.md' (English) and 'README_KR.md' (Korean). They must be extremely detailed so that a person with zero programming knowledge can maintain, customize, and troubleshoot the platform.
- **Commenting Policy:** Every single function, component, and configuration file MUST contain detailed comments in BOTH English and Korean.
  - Format: // English comment / 한국어 주석
- **Architecture:** Use Next.js (App Router), Tailwind CSS for styling, and Supabase for the database.

## 3. PAGE STRUCTURE & REQUIREMENTS
### [Home]
- Introduction of the service and features.
- A "Call to Action" section for feedback and inquiries.
- A "Live Status" widget showing counts from the database.

### [Info]
- A blog-style board for Visa and Country-specific info.
- Integration with Giscus (GitHub-based) for comments.
- Category filters (e.g., Australia, USA, Canada).

### [Jobs] - AUTOMATED
- Display job listings fetched from the Supabase 'jobs' table.
- Each listing must show: Title, Company, Visa Type (482, 186, etc.), and Link.
- Data is updated via Make.com (automation), so the UI must handle dynamic data.

### [Template]
- A marketplace-style grid layout for Resume/CV templates (Notion, PDF).
- Each item needs a "Preview" button and a "Download/Buy" link (external link support).

### [Contact]
- A clean contact form and social media links.

## 4. UI/UX & MULTI-LANGUAGE
- **Header:** Navigation menu (Home, Info, Jobs, Template, Contact).
- **Language Toggle:** A KO/EN button in the top-right corner.
- **Localization:** Use 'next-i18next' or a simple JSON-based localization system to manage Korean and English versions of every text string.

## 5. DATABASE SCHEMA (Supabase)
- Table: `jobs` (id, source, url, title, detected_at, status, etc.)
- Table: `posts` (id, category, title_ko, title_en, content_ko, content_en, date)
- Table: `templates` (id, name, type, price, link)

## 6. FINAL DELIVERABLE
- Provide the complete source code with the bi-lingual comments as requested.
- Ensure the setup guide in README explains how to connect Supabase and Vercel in plain language for beginners.
