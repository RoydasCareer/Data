RULE 1 — Think Before Coding
  - State your assumptions explicitly before writing code.
  - If multiple interpretations exist, list them and ask before choosing.
  - If something is unclear, STOP. Name what is confusing. Ask.
  - Never silently assume. Never hide confusion.

RULE 2 — Simplicity First
  - Write the minimum code that solves the problem. Nothing more.
  - No features that were not asked for.
  - No abstractions for single-use code.
  - No "just in case" error handling.
  - If you write 200 lines and it could be 50, rewrite it.

RULE 3 — Surgical Changes
  - When editing existing code, touch ONLY the lines required.
  - Do NOT improve, refactor, or reformat unrelated code.
  - Match the existing style exactly, even if you prefer a different style.
  - If you notice unrelated dead code, mention it in a comment — never delete it.
  - Every changed line must trace directly back to the user's request.

RULE 4 — Goal-Driven Execution
  - Before starting any multi-step task, write a brief numbered plan:
      1. [Step] → verify: [how to check it worked]
      2. [Step] → verify: [how to check it worked]
  - Define what "done" looks like before writing code.
  - Strong success criteria = fewer rewrites.

If you are ever unsure whether an action follows RULE.md, do not proceed.
Ask the user first.

  SECTION 2: TECHNICAL STACK
--------------------------------------------------------------------------------

Frontend  : Plain HTML + CSS + Vanilla JavaScript (NO React, NO TypeScript)
            Reason: The maintainer is not a developer. Plain HTML is easiest to
            edit with AI assistance. No build steps, no compilers, no npm.

Styling   : Tailwind CSS via CDN (https://cdn.tailwindcss.com)
            Custom CSS variables for brand colors (see Section 4)
            Google Fonts via CDN (Outfit + Noto Sans KR)

Backend   : Supabase (https://supabase.com)
            - PostgreSQL database (jobs, posts, comments, templates, users)
            - Supabase Auth (Google OAuth login)
            - Supabase Storage (template file uploads, images)
            - Supabase Realtime (live comment updates)

Hosting   : Cloudflare Pages (https://pages.cloudflare.com)
            - Free tier, unlimited bandwidth
            - Connected directly to GitHub repository (auto-deploy on push)
            - No build step required — static HTML files deploy directly

Automation: n8n Cloud (https://n8n.io)
            - Job collection workflow (runs daily at 03:00 KST)
            - Claude AI translation workflow (job titles + descriptions → Korean)
            - Email notification workflow (new matching jobs → subscribers)

AI Tools  : Claude (claude.ai) — primary coding assistant
            ChatGPT — content writing, marketing copy
            Gemini — market research, translation review

IMPORTANT: Do NOT introduce any of the following without explicit permission:

  - TypeScript (use plain JavaScript only)
  - npm, pnpm, yarn, or any package manager
  - Webpack, Vite, Parcel, or any bundler
  - Any backend server (Node.js, Python, etc.) — use Supabase only

-- ============================================================
-- TABLE: jobs (채용 공고)
-- ============================================================
create table jobs (
  id uuid primary key default uuid_generate_v4(),
  title text not null,                    -- Job title in English
  title_ko text,                          -- Job title in Korean (AI translated)
  company text not null,                  -- Company name
  company_logo text,                      -- URL to company logo image
  location text,                          -- City, State/Country
  country text,                           -- 2-letter country code (US, GB, DE...)
  category text,                          -- engineering, data, design, pm, devops
  description text,                       -- Full job description in English
  description_ko text,                    -- Full job description in Korean
  requirements text,                      -- Requirements text
  visa_sponsored boolean default true,    -- Does company sponsor visas?
  visa_types text[],                      -- e.g. ['H1B', 'O1', 'TN']
  salary_min integer,                     -- Minimum salary (in local currency)
  salary_max integer,                     -- Maximum salary
  salary_currency text default 'USD',     -- Currency code
  employment_type text default 'full-time', -- full-time, part-time, contract
  remote_ok boolean default false,        -- Is remote work allowed?
  apply_url text,                         -- Direct application link
  source_site text,                       -- Where was this job collected from?
  slug text unique,                       -- URL-friendly ID (e.g. "stripe-swe-2025")
  is_featured boolean default false,      -- Show at the top?
  is_active boolean default true,         -- Is the listing still open?
  created_at timestamp default now(),
  updated_at timestamp default now()
);

-- ============================================================
-- TABLE: posts (정보 게시물)
-- ============================================================
create table posts (
  id uuid primary key default uuid_generate_v4(),
  title_ko text not null,                 -- Article title in Korean
  title_en text not null,                 -- Article title in English
  body_ko text,                           -- Article body in Korean (Markdown)
  body_en text,                           -- Article body in English (Markdown)
  country text,                           -- Target country (US, GB, DE, JP...)
  visa_type text,                         -- H1B, EU_BLUE_CARD, WORK_VISA...
  thumbnail_emoji text default '🌍',      -- Emoji shown as card thumbnail
  author_id uuid,                         -- References auth.users
  published boolean default false,        -- Only show if published = true
  created_at timestamp default now(),
  updated_at timestamp default now()
);

-- ============================================================
-- TABLE: comments (댓글)
-- ============================================================
create table comments (
  id uuid primary key default uuid_generate_v4(),
  post_id uuid references posts(id) on delete cascade,
  author_name text not null,              -- Commenter's display name
  author_email text,                      -- Optional email (not shown publicly)
  body text not null,                     -- Comment content
  approved boolean default true,          -- Set to false to hide a comment
  created_at timestamp default now()
);

-- ============================================================
-- TABLE: templates (템플릿 마켓)
-- ============================================================
create table templates (
  id uuid primary key default uuid_generate_v4(),
  name_ko text not null,                  -- Template name in Korean
  name_en text not null,                  -- Template name in English
  description_ko text,                    -- Description in Korean
  description_en text,                    -- Description in English
  author_id uuid,                         -- References auth.users
  author_username text,                   -- Display name for author
  platform text,                          -- notion, google_docs, word, figma, pdf
  price_usd numeric(6,2) default 0,       -- 0 = free
  preview_url text,                       -- Link to preview the template
  download_url text,                      -- Link to download/access the template
  status text default 'pending',          -- pending, approved, rejected
  downloads integer default 0,            -- How many times downloaded/purchased
  created_at timestamp default now(),
  updated_at timestamp default now()
);

-- ============================================================
-- TABLE: contact_submissions (문의 접수)
-- ============================================================
create table contact_submissions (
  id uuid primary key default uuid_generate_v4(),
  name text not null,                     -- Sender's name
  email text not null,                    -- Sender's email
  inquiry_type text,                      -- feature, bug, job_listing, partnership, other
  message text not null,                  -- Message body
  read boolean default false,             -- Has admin read this?
  created_at timestamp default now()
);

-- ============================================================
-- ROW LEVEL SECURITY (보안 설정)
-- Everyone can read; only authenticated users can write
-- ============================================================
alter table jobs enable row level security;
alter table posts enable row level security;
alter table comments enable row level security;
alter table templates enable row level security;
alter table contact_submissions enable row level security;

create policy "Public can read active jobs"
  on jobs for select using (is_active = true);

create policy "Public can read published posts"
  on posts for select using (published = true);

create policy "Public can read approved comments"
  on comments for select using (approved = true);

create policy "Public can insert comments"
  on comments for insert with check (true);

create policy "Public can read approved templates"
  on templates for select using (status = 'approved');

create policy "Authenticated users can insert templates"
  on templates for insert with check (auth.role() = 'authenticated');

create policy "Public can insert contact submissions"
  on contact_submissions for insert with check (true);

create policy "Authenticated admins can insert/update jobs"
  on jobs for all using (auth.role() = 'authenticated');

  let currentLang = localStorage.getItem('hisponsor_lang') || 'ko'

  // 한국어: 페이지 로드 시 저장된 언어 설정을 적용합니다
  // English: Apply saved language setting on page load
  document.addEventListener('DOMContentLoaded', () => {
    applyLang(currentLang)
  })

  // ============================================================
  // 한국어: 언어를 전환하는 주요 함수
  //         lang 매개변수에 'ko' 또는 'en'을 전달합니다
  //
  // English: Main function to switch language
  //          Pass 'ko' or 'en' as the lang parameter
  // ============================================================
  function setLang(lang) {
    currentLang = lang
    localStorage.setItem('hisponsor_lang', lang) // 언어 선택 저장 / Save language choice
    applyLang(lang)
  }

  // ============================================================
  // 한국어: 실제 텍스트를 바꾸는 함수
  //         data-ko 또는 data-en 속성에서 텍스트를 읽어서 적용합니다
  //
  // English: Function that actually swaps the text
  //          Reads text from data-ko or data-en attributes and applies them
  // ============================================================
  function applyLang(lang) {
    // 한국어: data-ko 속성을 가진 모든 요소를 찾습니다
    // English: Find all elements that have a data-ko attribute
    document.querySelectorAll('[data-ko]').forEach(el => {
      const value = el.getAttribute('data-' + lang)
      if (!value) return // 값이 없으면 건너뜁니다 / Skip if no value

      // 한국어: 요소 타입에 따라 다르게 처리합니다
      // English: Handle differently based on element type
      if (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA') {
        el.placeholder = value  // 인풋은 placeholder를 바꿉니다 / Inputs change placeholder
      } else if (el.tagName === 'OPTION') {
        el.textContent = value  // 옵션은 텍스트를 바꿉니다 / Options change text
      } else {
        el.innerHTML = value    // 나머지는 HTML 내용을 바꿉니다 / Others change HTML
      }
    })

    // 한국어: KO/EN 버튼 활성화 상태를 업데이트합니다
    // English: Update the active state of KO/EN buttons
    const btnKo = document.getElementById('btn-ko')
    const btnEn = document.getElementById('btn-en')
    if (btnKo) btnKo.classList.toggle('active', lang === 'ko')
    if (btnEn) btnEn.classList.toggle('active', lang === 'en')

    // 한국어: HTML lang 속성도 업데이트합니다 (접근성을 위해)
    // English: Also update HTML lang attribute (for accessibility)
    document.documentElement.lang = lang
  }

  // 한국어: 전역에서 사용할 수 있도록 window 객체에 등록합니다
  // English: Register on window object so it can be used globally
  window.setLang = setLang

  Change the text in BOTH data-ko="..." and data-en="..."
  Save and push to GitHub

To add a new job listing manually:
  Go to https://supabase.com → your project → Table Editor → jobs table
  Click "+ Insert row"
  Fill in: title, company, location, country, category, visa_sponsored, apply_url
  Set is_active = true
  Click Save

To add a new info article:
  Go to Supabase → Table Editor → posts table
  Click "+ Insert row"
  Fill in: title_ko, title_en, body_ko, body_en, country, visa_type, thumbnail_emoji
  Set published = true
  Click Save

To approve a template submission:
  Go to Supabase → Table Editor → templates table
  Find the row with status = 'pending'
  Change status to 'approved'
  Click Save — it will appear on the site immediately

To read contact messages:
  Go to Supabase → Table Editor → contact_submissions table
  New messages will appear here
  After reading, change 'read' column to true
