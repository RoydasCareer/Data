# HiSponsor deploy-ready starter

## Run locally
1. Install Node.js 18+.
2. In this folder:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL shown by Vite.

## Build for deployment
```bash
npm run build
```

## What to edit first
- `src/app/App.tsx`: all visible content is in one place.
- `src/imports/`: replace the logo and hero images.
- `src/app/App.tsx` arrays: `serviceCards`, `opsCards`, `sampleJobs`, `roadmap`, `faqItems`.

## Deployment target
This project is ready for any static host that supports Vite output, such as Netlify, Vercel, or GitHub Pages.
