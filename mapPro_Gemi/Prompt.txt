# Role
당신은 3D 데이터 시각화와 프론트엔드 개발에 정통한 '수석 웹 개발자(Senior Web Developer)'입니다. 지금부터 내 요구사항을 바탕으로 로컬 환경에서 완벽하게 동작하는 '3D 지구본 기반 여행 기록 웹 서비스'를 처음부터 끝까지 작성해야 합니다.

# Project Overview
- **목표:** 구글 어스 형태의 3D 지구본 위에 2D 지도(구글맵, 네이버 지도 스타일)를 입히고, 사용자의 여행 기록(사진, 위치, 이동 경로)을 시각화하는 웹 서비스 구축.
- **환경:** 백엔드 없이 로컬 환경에서 100% 동작해야 함 (추후 호스팅 예정).
- **제약사항:** 네이버 블로그, 티스토리, 깃허브 블로그 등에 `iframe`으로 임베딩할 수 있도록 반응형 HTML/CSS/JS로 가볍게 구성할 것. (필요시 Vite 같은 가벼운 번들러 사용 가능, React/Vue 등 프레임워크 사용 여부는 가장 효율적인 방향으로 당신이 결정할 것).

# Core Features & Requirements

## 1. 3D 지구본 렌더링 (Mapbox GL JS v2, Globe.gl, 또는 Three.js 활용)
- 우주에서 바라보는 듯한 3D 지구본 형태를 구현하되, 표면 텍스처는 실사 위성 사진이 아닌 깔끔한 2D 지도 스타일(Vector Tile 또는 Raster Tile)을 적용할 것.
- 마우스 드래그로 회전, 휠로 줌인/줌아웃이 부드럽게 되어야 함.

## 2. 지역 표시 및 사진 라이브러리 (Local File API 활용)
- **지역 마커:** 지도 위에 특정 지역을 핀(Pin)으로 표시할 수 있어야 함.
- **사진 업로드 및 EXIF 연동:** 사용자가 로컬에서 여러 장의 사진을 업로드하면, 브라우저 단에서 사진의 EXIF 데이터(위도/경도)를 추출하여 자동으로 해당 위치에 마커를 생성하고 사진을 분류할 것. (EXIF 추출을 위해 `exifr` 같은 경량 라이브러리 사용).
- **수동 입력:** EXIF가 없는 경우 수동으로 위치를 지정할 수 있는 UI 제공.
- **사진 뷰어:** 지도 위의 마커를 클릭하면, 해당 지역에 저장된 사진들을 볼 수 있는 모달(Modal) 형태의 사진 뷰어/갤러리가 부드러운 애니메이션과 함께 나타나야 함.

## 3. 이동 경로 및 교통수단 애니메이션 (3D Arcs & Sprites)
- **경로 생성:** 출발지와 도착지를 설정하면 지구본 표면을 따라 이어지는 3D 곡선(Arc)을 렌더링할 것.
- **교통수단 설정:** 비행기, 자동차, 기차, 도보 등 교통수단을 선택할 수 있는 UI를 만들 것.
- **애니메이션:** 선택한 교통수단에 맞는 아이콘(예: 비행기 모양)이 출발지에서 도착지를 향해 곡선을 따라 계속해서 이동하는 애니메이션을 구현할 것. (눈에 거슬리지 않는 부드러운 속도와 주기로 반복).
- **Mock Data 적용:** 초기 화면 로드 시 테스트를 위해 다음 데이터를 기본으로 렌더링할 것.
  - 출발: 인천공항 (ICN)
  - 도착: 태국 방콕 수완나품 공항 (BKK)
  - 수단: 비행기 (비엣젯 항공 스타일의 빨간색 비행기 아이콘 적용)

# Implementation Steps (Autopilot Mode)
당신은 다음 단계를 순차적으로 실행하여 코드를 작성하고 파일 구조를 제시하십시오.

1. **Step 1: Project Setup & 3D Globe Base**
   - 프로젝트 폴더 구조 설계 및 필수 라이브러리(CDN 또는 npm) 세팅.
   - 2D 지도 스타일이 적용된 3D 지구본 렌더링 코드 작성.
2. **Step 2: Location & Photo Logic (EXIF)**
   - 로컬 이미지 다중 선택 UI 및 EXIF 데이터 추출 로직 구현.
   - 추출된 좌표를 바탕으로 지구본 위에 마커(Marker) 렌더링.
3. **Step 3: Photo Viewer UI/UX**
   - 마커 클릭 시 나타나는 세련된 HTML/CSS 기반의 사진 갤러리 모달 구현.
4. **Step 4: Routing & Animation**
   - 인천 -> 방콕 Mock Data를 활용한 3D 곡선 그리기.
   - 곡선을 따라 이동하는 비행기 아이콘 애니메이션 수학적 로직(Three.js 또는 Mapbox API 활용) 구현.
5. **Step 5: Embed Optimization**
   - 외부 블로그 임베딩을 고려한 CSS 반응형 처리 및 스크롤 간섭 방지 로직 추가.

자, Step 1부터 완벽한 코드를 작성해 줘. 코드는 복사해서 바로 실행할 수 있는 수준이어야 해.
